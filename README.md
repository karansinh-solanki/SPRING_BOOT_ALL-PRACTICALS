## 🚀 Topics Covered

### 01 · Spring Data JPA

Learn how Spring Boot applications interact with databases using JPA.

* Creating entities and performing CRUD operations
* Working with JPA repositories
* Writing custom database queries
* Understanding entity relationships
* Managing database transactions
* Implementing pagination and sorting

### 02 · REST APIs and Microservices

Explore the fundamentals of building RESTful backend applications.

* Creating REST APIs with Spring Boot
* Working with `ResponseEntity`
* Understanding layered architecture
* Handling request data
* Using DTOs (Data Transfer Objects)
* Implementing data validation
* Handling exceptions

### 03 · Spring Security

Understand the basics of securing backend applications and managing authentication and authorization.

* Implementing Basic Authentication
* User registration and login
* Password hashing using BCrypt
* Role-Based Access Control (RBAC)
* OAuth2 Resource Server
* JWT authentication
* Third-party login using OAuth2
* Configuring Cross-Origin Resource Sharing (CORS)

1. **Read the questions:** Start by reviewing the practical assignment questions.
